How to Play Memory Match

Step 1: Choose Your Mode

Select Single Player to practice, or Multiplayer to compete with a friend!

Step 2: Select Difficulty

Easy (4x3), Medium (4x4), or Hard (6x4). Start with Easy if you're new!

Step 3: Match the Cards

Click cards to flip them. Find matching pairs by remembering card positions.

Step 4: Use Hints

Stuck? Use the Hint button to highlight a matching pair. You get 3 hints per game!
